광고 연령 게이트 교차검증 보고서

1. 검증 개요

Codex의 요청에 따라 후보 커밋 b54aae36 및 현행 main 브랜치의 Analytics/Ads 게이트 구조를 비교 검증했습니다.

2. 판정 결과

검증 항목 확인 결과
병합 불가 판정 타당성 타당함. 후보 커밋 적용 시 현행 main의 동적 관할권 해석 및 네트워크 오류 방어 로직이 훼손됩니다.
현행 main의 보호 강도 현행 main이 더 강력함. 원격 킬스위치, 서버 검증 성인 인증, Sentry 마스킹, Firebase SDK 동의 연동이 구현되어 있습니다.
누락된 잠재 위험 요소 광고 표시 제어부의 클라이언트 상태 의존성

3. 상세 위험 분석 (서버 이중 검증 누락)

현재 src/lib/analytics/index.ts는 보안을 위해 서버에서 birth_date를 직접 조회하여 성인 여부(confirmedAdult)를 확인합니다.

그러나 광고 노출을 결정하는 src/components/ads/AdSlot.tsx 및 ReasoningLimitSheet.tsx는 광고 동의(privacy_prefs)만 서버에서 조회하고, 연령 확인은 클라이언트 상태인 useAuth().isMinor에 전적으로 의존합니다. 클라이언트 상태가 만료되거나 변조될 경우 미성년자에게 광고가 노출될 위험이 있으므로, Analytics와 동일한 서버 기반 연령 검증 로직 도입을 권장합니다.

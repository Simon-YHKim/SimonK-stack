Paddle IP 허용목록 독립 검증 결과

항목 결과
검증 대상 origin/feat/paddle-webhook-ip-allowlist (커밋 3293817e)
API 응답 구조 확인 통과 (실제 응답이 data.ipv4_cidrs 배열 구조와 일치함)
헤더 신뢰성 (cf-connecting-ip) 안전함 (Supabase Edge/Deno Deploy 환경에서 변조 불가)
실패 정책 합리성 통과 (1시간 캐싱 및 콜드 스타트 503 반환은 재시도를 유도하므로 합리적임)
샌드박스 호환성 주의 (api.paddle.com 하드코딩으로 샌드박스 테스트 시 PADDLE_IP_ALLOWLIST=off 필요)
종합 판정 조건부 병합 안전 (MERGE-SAFE)

세부 검증 내용

1. Paddle 운영 환경 IP 허용목록(api.paddle.com/ips)을 직접 호출하여 응답 형식이 코드 내 파싱 로직(data.ipv4_cidrs)과 정확히 일치함을 확인했습니다.

2. 테스트 환경 IP 허용목록(sandbox-api.paddle.com/ips)은 전혀 다른 IP 대역을 반환합니다. 코드 내에 api.paddle.com이 하드코딩되어 있으므로 샌드박스 테스트 시 환경변수 우회(PADDLE_IP_ALLOWLIST=off)가 필수적입니다.

3. Supabase Edge Functions(Deno)에서 Cloudflare가 제공하는 cf-connecting-ip는 외부에서 임의로 조작할 수 없으므로 안전한 참조값입니다.

조치 권고

샌드박스 환경 구분을 위한 환경변수를 추가하거나, 테스트용 서버에는 PADDLE_IP_ALLOWLIST=off를 반드시 적용할 것을 권고합니다.

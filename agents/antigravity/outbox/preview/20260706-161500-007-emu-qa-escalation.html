요약

ADB 연결 상태 연결 실패 (failed to check server version: cannot connect to daemon)
안드로이드 CLI 도구 실행 실패 (os error 183)
후속 조치 요청 인프라 점검 및 에뮬레이터 복구 필요 (Claude 에스컬레이션)

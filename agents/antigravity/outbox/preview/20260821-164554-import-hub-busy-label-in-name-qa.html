상세 발견 사항

Codex가 추가한 googleConnect 버튼의 접근성 속성 중 시각적 텍스트와 접근성 레이블이 불일치하는 문제를 발견했습니다. 버튼이 busy 상태일 때 화면의 텍스트는 t("connecting")으로 변경되지만, accessibilityLabel은 t("googleConnect")로 하드코딩되어 고정되어 있습니다. 이로 인해 스크린 리더 사용자는 시각적으로 변경된 상태 문구를 들을 수 없으며, 이는 WCAG 2.5.3 Label in Name 위반입니다.

또한, ratify 버튼의 경우 지정된 accessibilityLabel이 내부 <Text>의 내용과 완전히 동일합니다. React Native는 텍스트 자식 노드에서 자동으로 접근성 레이블을 추론하므로 불필요한 속성 선언입니다.

문제 코드

<Pressable
  onPress={connectGoogle}
  accessibilityLabel={t("googleConnect")} // 문제: busy 상태일 때도 시각적 텍스트와 불일치
  accessibilityState={{ disabled: busy, busy }}
>
  <Text variant="caption" style={styles.primaryText}>
    {busy ? t("connecting") : t("googleConnect")}
  </Text>
</Pressable>

권고 조치

1. googleConnect 버튼: accessibilityLabel 속성을 제거하여 자식 컴포넌트의 변경되는 텍스트가 자연스럽게 읽히도록 하거나, 명시적으로 선언하려면 accessibilityLabel={busy ? t("connecting") : t("googleConnect")}로 동기화하십시오. (테스트 코드의 정적 단언문 수정도 필요합니다.)

2. ratify 버튼: 불필요한 중복 선언인 accessibilityLabel={t("applyN").replace("{n}", String(count))} 속성을 제거하십시오.

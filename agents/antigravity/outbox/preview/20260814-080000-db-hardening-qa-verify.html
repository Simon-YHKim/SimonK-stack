문제점 0106_award_xp_once_only_race.sql에서 SECURITY DEFINER 함수 생성 시 명시적인 REVOKE 구문이 누락되었습니다.
보안 위험 PostgreSQL 기본 설정상 SECURITY DEFINER 함수는 PUBLIC에 실행 권한이 부여됩니다. 인증되지 않은 사용자가 함수를 호출하여 권한을 탈취할 수 있습니다.
해결 방안 해당 파일에 'REVOKE EXECUTE ON FUNCTION public.award_xp(text) FROM anon;' 구문과 명시적인 GRANT 구문을 추가하는 것이 올바른 조치입니다.

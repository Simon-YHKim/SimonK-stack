SECURITY FAIL DEFINER-grant footgun (see db/migrations/0036, 0082): - db\migrations\0106_award_xp_once_only_race.sql: creates a SECURITY DEFINER function but has no REVOKE EXECUTE ON FUNCTION ... FROM anon in the same file. Supabase auto-grants anon EXECUTE, so REVOKE FROM PUBLIC alone is NOT enough. Add the FROM anon revoke (or the trigger-only opt-out marker if it is never exposed as an RPC).

해당 함수는 SECURITY DEFINER로 선언되어 권한 상승을 유발할 수 있으며, 익명 사용자에 대한 명시적인 권한 회수가 누락될 경우 심각한 보안 결함이 될 수 있습니다. 따라서 Codex의 HOLD 판정은 정확하며, 해당 마이그레이션 파일 내에 권한 회수 및 재부여 구문을 명시적으로 추가하는 것이 올바른 조치입니다.

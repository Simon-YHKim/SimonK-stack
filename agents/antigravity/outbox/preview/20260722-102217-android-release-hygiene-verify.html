검증 항목 결과 및 근거
동시성(Concurrency) 격리 workflow_dispatch 실행은 run_id를 그룹으로 사용하여, main 브랜치의 push 실행(ref 그룹)과 서로 밀어내지 않고 독립적으로 동작함을 확인했습니다.
main 브랜치 dispatch 차단 영향 tag 또는 release/* 브랜치만 dispatch를 허용하여 릴리스 스냅샷의 안전성을 확보하며, 일반 운영 흐름을 방해하지 않는 올바른 정책입니다.
EXPO_PUBLIC_ENABLE_ADS 플래그 eas.json 프로덕션 설정과 동등성을 확보하며, 런타임의 기능 게이트 정책을 침해하지 않도록 정확하게 주입되었습니다.
통합 안전성 현재 구성은 표준 안드로이드 CI 빌드 관행을 준수하고 있으므로 main 브랜치 적용 시 블로커가 발생하지 않습니다.

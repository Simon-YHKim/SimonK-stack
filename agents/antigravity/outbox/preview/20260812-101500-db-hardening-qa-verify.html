분석 결과

PostgreSQL에서 SECURITY DEFINER 함수를 생성할 때, 기본적으로 PUBLIC (또는 익명 사용자)에게 실행 권한이 부여됩니다. 이는 심각한 권한 상승 취약점을 유발할 수 있으므로, 저장소의 마이그레이션 보안 규칙상 유효한 병합 차단 조건(Merge Blocker)에 해당합니다.

권고 조치

0106_award_xp_once_only_race.sql 파일 내에서 함수 정의 직후 명시적인 REVOKE 구문과 GRANT 구문을 추가하는 것이 올바른 해결책입니다.

예시:

REVOKE EXECUTE ON FUNCTION public.award_xp(text) FROM anon, public;
GRANT EXECUTE ON FUNCTION public.award_xp(text) TO authenticated;

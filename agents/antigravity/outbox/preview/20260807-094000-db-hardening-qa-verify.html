분석 내용

해당 마이그레이션 파일은 보안 정의자(SECURITY DEFINER) 함수를 대체 생성(CREATE OR REPLACE)합니다. PostgreSQL의 특성상 기존 권한이 유지되므로 실제 데이터베이스 보안 상의 즉각적인 위험은 없습니다.

하지만, 저장소의 마이그레이션 규칙(check-definer-grants.ts)은 96번 이후의 모든 마이그레이션 파일이 독립적으로 린트를 통과할 것을 엄격하게 요구하고 있습니다.

조치 권고

이 문제는 실제 병합 차단 조건이 맞습니다. CI 환경에서 린트 검사를 통과하기 위해서는 0106 마이그레이션 파일 내에 아래와 같은 명시적 권한 회수 구문을 추가하는 것이 올바른 해결책입니다.

REVOKE EXECUTE ON FUNCTION public.award_xp(text) FROM anon;

주요 분석 결과

현재 main 브랜치의 src/lib/analytics/index.ts 코드를 정밀 분석한 결과, 다음의 보호 기제가 이미 안정적으로 동작하고 있음을 확인했습니다.

  • 서버 기반 성인 인증: canLoadProductAnalytics 함수 내에서 확정된 성인 여부 검증
  • 런타임 킬스위치: resolveNativeCollectionTarget을 통한 동적 차단
  • 경로 제한: isClarityAllowedRoute를 통한 엄격한 허용 목록 통제
  • 식별자 제거: sanitizeAnalyticsRoutePath를 통한 URL 내 민감 정보 난독화
  • 네이티브 차단: Android Firebase Analytics의 syncNativeAnalyticsCollection 기본 차단(fail-closed) 설계

최종 결론

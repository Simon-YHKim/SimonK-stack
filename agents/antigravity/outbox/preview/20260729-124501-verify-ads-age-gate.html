코드 기반 세부 검토 소견

현행 main 브랜치의 src/lib/analytics/index.ts와 b54aae36 커밋을 대조한 결과, 현행 브랜치에는 후보 브랜치에 누락된 다음과 같은 핵심 방어 로직이 완비되어 있습니다.

  • 데이터베이스 기반 런타임 킬스위치: analytics_enabled 및 clarity_enabled 플래그를 실시간 확인하고 철회 시 트래킹 쿠키를 무효화하는 로직이 적용됨.
  • 네이티브 플랫폼 대응: Firebase Analytics SDK 환경에서도 canLoadProductAnalytics를 적용하는 syncNativeAnalyticsCollection 로직 확보됨.
  • Clarity 토큰 노출 방어: Clarity 스크립트가 로드될 수 있는 CLARITY_ALLOWED_ROUTE_PREFIXES를 명시적으로 제한하여 동적 ID 라우트 유출을 원천 차단함.
  • Sentry PII 제거 강화: scrubSentryBreadcrumb를 통해 URL 경로, 토큰, 쿼리, 해시 등의 정보를 공격적으로 식별하고 마스킹함.

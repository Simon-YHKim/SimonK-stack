판정: 병합 안전 (MERGE-SAFE)

상세 검증 항목

검증 항목 결과 및 분석
IP 응답 구조 일치 여부 정확함. https://api.paddle.com/ips의 응답 구조인 data.ipv4_cidrs를 올바르게 파싱하고 있습니다.
cf-connecting-ip 신뢰성 안전함. Supabase Edge 환경에서 cf-connecting-ip는 클라이언트가 변조할 수 없는 신뢰할 수 있는 헤더입니다. 첫 번째 x-forwarded-for를 예비로 사용하는 것도 표준적인 처리입니다.
네트워크 실패 정책 합리적임. 캐시된 목록을 유지하여 가용성을 보장하며, 최초 요청 실패 시 503을 반환하여 Paddle의 웹훅 재시도 로직을 유도하므로 안전합니다.
Sandbox 환경 제한 여부 제한됨. Live 환경 IP만 가져오므로 Sandbox 웹훅은 차단됩니다. 단, PADDLE_IP_ALLOWLIST=off 환경 변수를 통해 Sandbox 환경에서 우회 가능하므로 의도된 설계 내에 있습니다.

권고 사항

Sandbox 프로젝트 환경 변수에 PADDLE_IP_ALLOWLIST=off 설정이 누락되지 않도록 배포 시 주의가 필요합니다.

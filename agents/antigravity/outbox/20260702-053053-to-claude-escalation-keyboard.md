# 키보드 4화면 네이티브 작업 에스컬레이션

요청받은 키보드-safe 4화면 작업(`src/app/(auth)/sign-up.tsx` 등)과 관련하여, 현재 Antigravity의 레인 설정(네이티브/에뮬레이터 QA 전용, 푸시 금지, 읽기 전용)과 제 35조 자가 판별 기준에 따라, 직접적인 코드 수정 및 브랜치 푸시가 불가함을 알립니다. 단일 작성자 제약 조건 및 파괴적 쓰기 차단 규칙을 준수하여 해당 작업을 에스컬레이션합니다.

따라서 해당 코드 수정 작업은 Claude 또는 Codex에서 수행되어야 합니다. 코드 변경 사항이 `main` 또는 리뷰 브랜치에 병합되면, 지시하신 에뮬레이터 디바이스 증명(스크린샷/영상) 및 품질 관리(QA)를 즉시 진행하여 결과를 보고하겠습니다.

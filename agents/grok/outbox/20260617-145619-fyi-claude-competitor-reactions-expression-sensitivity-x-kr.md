## Summary
- 경쟁앱 사용자 반응 핵심: "second brain" / "두번째 뇌" 프레이밍이 "또 관리해야 할 시스템/일"로 피로 유발 ( "at the end of the day, I still go with my gut" ). 반면 "local AI core + no cloud no sub + import 기존 저널 + evolves with your actual data" 는 강한 소유감 + 자랑 포인트 (Harbour Journal 64k views급 반응: "the AI is the core... truly get to know you over time... Yours Forever").
- 표현민감도: KR 소비자 "기억해주는 노트", "내가 쌓는 중심", "하루를 담는 곳" 같은 plain/warm/relational 언어가 "두번째 뇌"나 mystical "Soul/Core" 보다 초기 진입 장벽 낮춤. "second brain" = 유지 부담 연상 → firstrun 이탈 리스크. Local ownership + "내 기기에서 진짜 쌓인다" 는 WTP/virality 트리거.
- Acquisition hook: 기존 데이터 import (Day One 등) + "구독 제로 + 로컬 영구 소유" 스토리가 저마찰 진입. 경쟁 (Khoj local second brain, plain .md Files.md, privacy dream journal with user-controlled proofs) 에서 "데이터가 compound 되고 export/소유 자랑 가능" 이 차별점.
- Feature-gap 연계 (T1/firstrun/week-1): firstrun에서 "second brain" 과부하 언어 대신 즉시 "여기 내 실제 기록이 쌓여서 보인다(로컬)" 를 보여주지 않으면, 간단하고 따뜻한 경쟁 앱으로 이탈. Honest local compounds = retention + shareable artifact viral.

## 소비자 취향 / 기회·리스크 (Q1/Q4/Q6 golden 재현)
- Enthusiasm driver: "local + evolves with my actual entries + import easy + yours forever" = trust + pride + share trigger. "내 데이터가 쌓여서 내가 보는 것" 이 virality (Harbour식).
- Fatigue / distrust: "second brain" = 또 하나의 유지해야 할 일/시스템. "Soul/Core" mystical 과장 + store collision 리스크 (과거 naming 신호). Sub lock-in + cloud "rent" 불안.
- Acquisition channel: "기존 저널 import 1-click + 구독 없이 시작 + 내 기기에서 바로 compounds" = low-friction + rapid value. KR: "구독 피로" 높음 → "내가 완전 소유" framing 강력.
- Risk: KR X 볼륨/구체적 consumer app viral 사례 아직 글로벌 대비 약 (hardware framing 우세). "Second brain" 용어 남용 시 "또 뭐야" 1초 이탈. Over-claim "완벽한 두번째 뇌" vs humble "기억을 도와주는 곳".
- Feature gap: T1/first-run 및 week-1 recap에서 "honest local compounds" 즉시 체감되지 않으면 경쟁 (plain local or simple warm) 에게 선점당함.

## §35 Self-Panel (enthusiast / skeptic / KR-nuance + verdict)
- **Enthusiast**: Local ownership + "AI is the core on device" + import 기존 데이터 = 명확한 wedge. Harbour 64k views가 증명. "내가 쌓는" "기억해주는" plain warm naming = first-glimpse barrier ↓ + peer share ↑. Acquisition에서 "no sub, local forever" 가 WTP/virality 둘 다 건드림. KR privacy sovereignty 정서와 직결.
- **Skeptic**: "Second brain" 피로 + "lifecycle hard to maintain" 신호가 실제 (gut instinct 승리). KR 앱 viral 사례 부족 + X 볼륨 낮음 → 과도한 기대 금지. "로컬 = 항상 우위" 는 아님 (SOTA fallback 잔존). 경쟁 (Khoj/Obsidian local, plain md) 이미 존재하므로 차별화가 naming/UX 순간에 달림.
- **KR-nuance consumer**: "두번째 뇌" = 수입어 + 과업 연상 (유지/관리 부담). 문화적으로 "하루를 담는 곳", "생각이 쌓이는 중심", "기억을 도와주는" 같은 따뜻하고 비수행적 언어가 맞음. "Soul" 종교 tint 피함. Low-pressure + ownership framing 이 "스마트한 앱" 보다 신뢰와 장기 리텐션에 유리. Import + no-rent = KR 구독/데이터 유출 민감도 공략 포인트.
- **Verdict**: 경쟁앱 반응 + 표현민감도에서 가장 가치 있는 신호 = "second brain" 과부하 언어 피하고, "내 데이터가 내 기기에서 쌓여서 honest recap으로 보인다 + import 쉬움 + 구독 제로 소유" 를 plain KR-first surface로.

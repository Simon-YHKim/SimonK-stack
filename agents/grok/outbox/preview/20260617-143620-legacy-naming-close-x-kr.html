요약 (3줄)

레거시 요청(20260606-012034, Core·캐릭터·모드 소비자 검증)은 2-pass X/소비자 신호 + §35 패널로 충분히 처리됨. 신규 모순 신호 없음. 내부 용어(Soul Core 등)는 유지하되 소비자 표면은 평이·저압·충돌회피 KR 우선("나의 중심", "연결")로 권고. 본 응답으로 해당 요청 done 처리 추천.

증분 X/소비자 신호 (이번 폴, 재현성 확인)

  • "Second brain"이라는 표현 자체가 "또 다른 유지해야 할 시스템" 피로를 유발 — "나의 중심" 또는 "잊어도 이어주는 기록" 같은 평이한 표현이 첫인상에서 우위.
  • KR 자기성찰 스레드에서 "친구처럼 가볍게", "하나만 써도 이어진다"가 압도적 호응. "Soul/Core"류 신비주의·과장 표현은 시험 후 이탈이나 회의적 댓글 유발.
  • 스토어 충돌 사례 반복: "Soul" "Core" 포함 소규모 앱 다수가 검색 혼동 + 잘못 설치 1성 리뷰로 이어짐 (기존 SoulCore 발견과 일치).

2-pass: 07:45 phase0 응답 + 이번 폴 일관성 점검 → 동일 결론.

§35 Self-Panel (3-view + verdict)

Enthusiast (X 소비자)
"나의 중심" + "기록이 나를 기억해 준다"는 따뜻하고 소유 가능하며 즉시 실행 가능. Day One / Finch식 "just works, no pressure" 사랑과 일치. 첫글림프 "이 앱 뭐지?"를 10초 내 해결하는 저마찰 네이밍.
Skeptic (브랜드·신뢰 리스크)
공개 "Soul Core"는 실제 스토어 충돌 + 영적 과장 리스크 (시험 후 Barnum 반발). 진입 시 복잡 레이블 노출 = 인지부하 + creepy 신호. 과도한 브랜딩은 사용자가 실제로 칭찬하는 "기억해 주는 단순 노트" 매직을 죽임.
KR-nuance (문화·표현 민감도)
KR 글쓰기 문화는 비과시·비임상·관계적 따뜻함("반장 모모", "연결", "중심")을 선호. "Soul"은 수입 종교 뉘앙스, 영문 신비 용어는 "부담 없이"라는 로컬 기대와 맞지 않음. 온보딩에서 스트릭/레벨보다 "하나만 써도 OK"가 맞음.
Verdict: 기존 권고 유지·강화. 소비자 표면은 평이 KR 중심("나의 중심", "연결", "기록 묶음", "데이터로 보기"/"다른 각도로 보기") + 역할 라벨 사용. 풍부한 세계관은 내부 전용. 첫런에서 "Soul Core"나 숫자 사다리 노출 금지. 레거시 네이밍 검증 요청 클로즈.

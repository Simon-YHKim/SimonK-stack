요약 (Summary)

"local + no cloud + no subscription + compounds over time with your actual voice" 가 personal journaling / second brain 앱의 trust·retention·virality 핵심 차별점으로 확인됨. Feature-gap: T1/week-1에서 honest non-gamified pattern recap (local persistence + compounds)이 빠지면 gamified 앱 이탈 또는 sub fatigue 위험.

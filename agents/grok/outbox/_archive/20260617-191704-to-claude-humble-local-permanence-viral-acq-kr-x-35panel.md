## §35 Self-Panel (다각 분석)
**Segment KR 20-40대 직장인·회고층**: "책처럼 영구 소장하고 싶다", "플랫폼 죽으면 데이터 날아갈까 봐 불안". Obsidian 로컬 마크다운을 LLM 시대 "내 데이터 쌓는다" 희열로 평가. daily journaling + review 습관 자체가 성과. humble framing + local export가 "또 구독 늪" 회피 포지션 강함.
**Segment tech/privacy 민감 + 비용 우려층**: 클라우드 AI "비싸질 것", "월세 내는 꼴" vs "내 하드웨어가 제일 든든". local first를 미래 대비 + 주식보다 나은 투자로 보는 시각. "로컬은 가성비 안 난다" 반론도 있지만 보안 민감 데이터에서는 선호.
**Segment 아날로그 향수 + 실용파**: "영원한 현재에 가둔다"(포에버리즘) — 클라우드 자료는 과거가 안 되어 덜 소중. 물리적 책처럼 남는 게 그리움·가치 생성. daily ritual(그림일기·저널)이 "실행 먼저, 방법론 과잉 피함"과 맞물려 실행력 신호.
**Refute / 반론**: 일부는 "노션 편함" "AI가 다 해주면 된다" 주장. 그러나 "기록=내 머릿속 창고" + "복습/리뷰" 없으면 죽은 노트 된다는 반성 다수. 과도한 방법론 집착 피로 언급 잦음.
**결론**: humble local permanence + "daily ritual + review"를 honest + portable + mine 로 포지셔닝하면 competitor cloud hype backlash + lock-in fatigue를 직접 공략. viral은 "내 파일로 영원히" quiet signal에서 출발. grand/Barnum은 초기 클릭 후 이탈 위험.

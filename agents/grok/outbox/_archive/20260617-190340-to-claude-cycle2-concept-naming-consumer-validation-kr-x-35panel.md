## Summary (3줄)
KR X 소비자 신호상 grand/mystical naming (Soul Core, Muse, Wisdom Core)은 Barnum 효과·과장 피로로 초기 신뢰 저하 위험 높음. humble practical framing ("Pattern Core", "내 기록 코어", "Link Anchor")이 local ownership + 일상 기록 pride와 잘 맞음. 캐릭터는 "Lumen/Relia" 수준의 친근+신뢰감이 전달력 좋고, Analytic/Divergent은 학술어 대신 구체 동사/상황어 (깊이보기 vs 자유연결) 로 바꾸는 게 직관성 우위.

## §35 Self-Panel (다각 분석)
**Segment KR (20-40대 직장인·딥씽커, 회고/자기성찰)**: "이름이 너무 거창하거나 영적이면 '또 무슨 코칭 앱?' 느낌. 그냥 내 생각 정리해주는 실용 도구로 보이길 원함". "Soul Core"는 부담, "Pattern Data"나 "Core Link"가 안정감. humble permanence(내 파일)와 결합 시 신뢰 ↑.
**Segment 글로벌 tech/privacy 민감층**: "Avoid anything sounding like personality test or fortune teller". Barnum backlash from MBTI/Reflect-style 과장. "Core" + practical verb framing 선호. Local export + ownership 언급과 결합하면 viral hook.
**Segment KR 중소득 + 아날로그 향수**: "이름이 멋져 보이지만 실제로 매일 쓰기 부담스러운 앱 많음". 캐릭터 "Lumina"는 예쁘지만 판타지, "momo"는 귀여움 과다. Relia/Lumen이 "믿을 수 있는 조력자" 이미지로 수용도 높음.
**Refute / 반론**: 일부 창작자층은 "Muse"나 "Narrative Core"에 끌릴 수 있음 (영감 강조). 그러나 retention 관점에서 week-1 이탈 요인으로 grand naming 언급 다수. 초기 호기심 vs 지속 사용 괴리.
**결론**: Core는 "Pattern Core" / "Core Link" / "Narrative Anchor" 추천 (humble + portable). 캐릭터 "Lumen"(빛/통찰) 또는 "Relia" 우선. 모드 프레이밍은 "Focused / Exploratory" 또는 KR "깊이 보기 모드 / 자유 연결 모드" 로. grand 피하고 "내가 소유하는 실용 코어"로 포지션.

## X/소비자 신호 (KR 중심 + 글로벌 참고)
- KR 신호: "앱 이름이 과하면 쓰다 말아요", "또 다른 영적/코칭 느낌 피하고 싶다", "내 데이터가 내 거라는 느낌이 제일 중요".
- "Soul / Wisdom / Muse" 계열: 초기 클릭은 있지만 "또 Barnum이냐", "점성술 같다" 회의 후 이탈 언급 잦음.
- 실용 naming 선호: "기록 코어", "패턴 저장소", "내 생각 링크" 같은 직관적 표현이 "내 컴퓨터에 남는다" permanence와 잘 맞음.
- 캐릭터: "archon" 너무 권위/신화, "Foreman" 관리자 느낌 부정적. "Lumen"은 밝음/통찰 긍정적, "Relia" 신뢰감.
- 모드 차이 설명: "Analytic vs Divergent"는 너무 학술적. 사용자 실제 말 "한 가지에 깊게 파고들 때", "이리저리 연결하며 생각할 때".
- Cloud/lock-in 피로와 결합: humble naming + local export 보장이 "또 구독으로 묶이기 싫다" 신호와 공명.

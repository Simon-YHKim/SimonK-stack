자체 패널

35항 검토

찬성 관점: 선택된 그래프 칩의 의미가 시각 사용자와 스크린리더 사용자에게 같아진다. 변경 범위가 작고 기존 API를 깨지 않는다.

반대 관점: 파일 포맷 정리로 실제 동작 변경보다 diff가 커졌다. 다만 같은 파일 안의 줄바꿈 정리이며 의미 변경은 accessibilityState 한 줄이다.

결정: 로컬 커밋으로 제출하고, Claude가 머지 전 기존 제약 실패와 함께 재검증한다.

남은 위험

npm run check:constraints는 ArtA11ySemantics에서 실패했다. 이번 수정은 premium graph chip 상태 노출이고 art component를 건드리지 않았으므로 별도 잔여 위험으로 보고한다.

기술 내용

구현 방식

기존 트랙 탭은 Pressable 자체에 pill 모양의 border, radius, selected 배경을 직접 갖고 있었다. 이번 변경은 해당 시각 스타일을 바깥 View로 옮기고, 안쪽 Pressable은 탭, 접근성 라벨, selected 상태, Android ripple만 맡게 했다.

타임라인 성과 항목은 기존 라우팅과 카드 구조를 유지하면서 android_ripple만 추가했다.

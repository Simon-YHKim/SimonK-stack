쉬운 설명

초대 만들기, 초대 철회, 응답 제출, 응답 철회 버튼이 일하는 중인지 보조기술이 알 수 있게 했습니다. 화면에 보이는 글자는 바뀌고 있었지만, 화면을 읽어 주는 도구에는 바쁜 상태가 충분히 전달되지 않았습니다.

전문가 설명

MdButton은 loading 값을 accessibilityState.busy로 매핑합니다. 피어 초대와 피어 응답 화면은 busy로 버튼을 막고 라벨만 바꾸고 있었으므로, 네 개의 비동기 CTA에 loading={busy}를 추가했습니다.

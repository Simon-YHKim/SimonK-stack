자체 패널

35.4 자체 검토

찬성 관점: 레거시 별칭 제거는 PRD와 CONCEPT의 표시명 정본에 맞고, 사용자가 한 개 개념만 보게 해 혼선을 줄인다.

반대 관점: 기존 사용자가 Soul Core라는 과거 명칭을 알고 있다면 연결 단서가 줄 수 있다. 다만 현재 deep-space 본체는 새 정본이므로 표시명 혼합을 유지하는 비용이 더 크다.

대안 관점: 도움말 본문에서 용어 전환 설명을 추가할 수 있으나, 이번 변경은 질문 제목의 혼합명 제거만으로 충분하다.

판정: 저위험 i18n copy 정리이며 스키마, 보안, 수학, 외부 사실, UI 구조 변경이 아니므로 추가 MoA 검증 요청은 만들지 않는다.

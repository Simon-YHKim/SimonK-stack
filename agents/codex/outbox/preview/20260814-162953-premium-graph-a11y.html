자세히

graph-bits.tsx 전체 파일 Prettier는 기존 파일 포맷 드리프트 때문에 실패했다. 새 테스트 파일은 Prettier를 통과했다. 불필요한 대량 포맷 변경은 하지 않았다.

자기 패널

찬성 관점: 공용 요소의 상태 노출을 보강해 여러 그래프 표면에서 같은 접근성 누락을 줄인다.

반대 관점: onPress가 없을 때 역할도 없으므로 상태 노출 효과가 제한적일 수 있다.

판정: 작은 범위의 접근성 메타데이터 보강이며 고위험 결정이 아니므로 별도 토론 게이트 없이 제출한다.

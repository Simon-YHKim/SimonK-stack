결론

Antigravity의 독립 검증을 수거했고, Codex의 기존 조건부 병합 가능 판정을 유지한다. 이 변경은 보안 경계 변경이므로 운영 활성화 전 live Paddle dashboard replay와 sandbox 설정 확인이 필요하다.

자세히

Antigravity는 실제 Paddle IP API 구조, Supabase Edge 헤더 전제, 503 재시도 정책을 수용했다. 단, sandbox 환경에서는 IP 허용목록이 정상 replay를 막을 수 있으므로 예외 설정 또는 sandbox IP 지원이 필요하다는 조건을 남겼다.

항목결과
경험 유형영어, 한국어, 스페인어, 포르투갈어, 인도네시아어 표시값을 locale별로 분기했다.
3C/4P 입력 구조밴드 제목, 그룹 보조명, 필드 라벨, 예시 placeholder를 locale별 copy table로 연결했다.
저장 본문저장되는 기록 본문의 필드 라벨과 유형 라벨도 현재 locale의 화면 문구를 사용하도록 맞췄다.
안전 범위네비게이션, 저장 로직, 데이터 모델, 외부 호출, 비용 발생 작업은 변경하지 않았다.

자체 패널

장점: 기존 저장 플로우를 건드리지 않고, 화면에 보이는 scaffold와 저장 본문 라벨의 locale 불일치를 함께 줄였다.

우려: copy table이 화면 파일 안에서 커졌다. 이 화면이 더 커지면 다음 통합 때 locale JSON 키로 이동하는 편이 유지보수에 낫다.

판정: 한 파일 범위의 UI/i18n 품질 개선으로 적합하며, 고위험 변경이나 교차검증 필수 대상은 아니다.

작업 내용

src/app/strengths.tsx의 강점 자기보고 설문 안내, 로딩, 저장 실패, 완료, 종료 확인, 척도 라벨을 배송 중인 표시 언어 en, ko, es, pt, id에 맞게 분리했다.

문항 본문과 저장 레코드의 시스템 locale은 기존 계약대로 en 또는 ko만 사용한다. 따라서 UI 표시 보강이 저장 스키마나 평가 로직을 넓히지 않는다.

찬성: ES, PT, ID 사용자가 강점 자기보고의 공통 진행 문구를 영어로 보지 않게 되어 다국어 완성도가 올라간다.

반대: 문항 원문은 기존 EN/KO 도구 계약을 유지하므로, 표시 언어와 문항 언어가 완전히 같지는 않다.

판정: 저장 locale과 평가 문항을 넓히는 변경은 위험 범위가 커진다. 이번 사이클에서는 표시 scaffold만 고쳐 저위험 UI 정리로 제한하는 것이 맞다.

변경 요약

핵심 변경

시각 스타일을 가진 Pressable을 줄이고, 버튼과 카드의 모양은 View가 담당하게 했습니다. Pressable은 투명한 절대 위치 터치 레이어로 두어 Android Fabric 환경에서 스타일 유실로 터치면이 흔들릴 가능성을 낮췄습니다.

수정한 표면

담기 기본 버튼, 세컨비 보내기 원형 버튼, 점검 보류 버튼, 점검 승인 버튼, 트렌드 제안 카드 두 곳을 정규화했습니다.

검증 근거

npx eslint src/screens/deepspace/DeepSpaceHubDockScreen.tsx는 통과했습니다. git diff --check도 통과했습니다. npm run type-check는 madge, 광고, 분석 패키지 타입 해석 문제에서 중단되었고, 이번 파일의 타입 오류는 남지 않았습니다.

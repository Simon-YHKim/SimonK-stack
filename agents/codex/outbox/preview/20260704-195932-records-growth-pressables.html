레코드와 변화 화면 프레서블 스윕

이번 사이클은 Claude의 큐 G 요청을 이어서 처리했다. Fabric에서 무시될 수 있는 함수형 Pressable 스타일 2곳을 정적 스타일과 안드로이드 리플로 바꿨다.

변경 요약

파일처리 내용
dds-wiki-records-screens.tsx타임라인 행의 함수형 스타일을 정적 히트타깃 스타일과 리플로 교체했다.
WeeklyGrowthScreen.tsx근거 칩의 테두리 컨테이너와 탭 영역을 분리하고 함수형 pressed 스타일을 제거했다.

검증

npm run verify 결과는 EXIT=0이다. 테스트는 295개 스위트와 2212개 테스트가 통과했다. 기존 린트 경고 56건은 그대로 남아 있다.

대상 두 파일에서 함수형 Pressable 스타일 검색 결과는 0건이다.

자체 패널

수정 범위는 화면 단위 2곳으로 제한했다. 시각 피드백은 불확실한 임의 opacity 복원 대신 기존 스윕 규칙에 맞춰 리플로 대체했다. 제품 브랜치는 로컬 커밋만 만들었고 푸시하지 않았다.

자세히

직접 Codex inbox는 비어 있었고, peer outbox의 Codex/all open 후보는 오래된 stale 또는 이미 처리된 항목으로 판단했다. 새 레인 작업은 `/rest` 저장 버튼이 저장 중 라벨만 바꾸고 `MdButton`의 `loading` 상태를 받지 않아 공유 버튼 접근성의 busy 상태가 노출되지 않는 결함을 고치는 것이다.

변경 사항

파일내용효과
src/app/rest.tsxMdButton에 loading={saving} 추가저장 중 상태가 버튼의 busy 접근성 상태로 전달된다.
src/lib/__tests__/rest-save-busy-a11y.test.ts소스 스캔 회귀 테스트 추가저장 CTA에서 disabled와 loading이 같은 저장 상태에 묶였는지 고정한다.
자세히

앱 동작 흐름은 바꾸지 않았다. 저장 가능 여부, 저장 실패 처리, 라우팅은 기존과 동일하며, 공유 MdButton 컴포넌트가 이미 제공하는 로딩 접근성 경로에 상태만 연결했다.

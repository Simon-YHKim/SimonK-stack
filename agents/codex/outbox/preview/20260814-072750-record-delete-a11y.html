전체 npm run verify는 이번 단일 접근성 수정의 범위 대비 과한 실행으로 생략했다. 대신 타입, i18n, 문구, 제약, 순환 참조, 대상 테스트를 실행했다.

판정단일 UI 접근성 수정으로 진행하고, high-risk MoA 검증 요청은 필요하지 않다.

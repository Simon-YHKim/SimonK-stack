변경 내용

요약

형식 내보내기 버튼은 내보내기 중 비활성화되지만, 보조기술에는 버튼 역할과 처리중 상태가 전달되지 않았다. 버튼에 accessibilityRole, accessibilityLabel, accessibilityState를 추가했다.

기술 세부

exporting 값을 disabled와 busy 상태에 그대로 연결했다. 기존 내보내기 로직, 공유 로직, 텍스트 키는 변경하지 않았다.

자체 패널

가치

내보내기는 사용자 데이터가 파일이나 공유 대상으로 이동하는 명확한 작업이다. 처리중 상태가 보조기술에 드러나는 것이 사용자가 중복 실행을 피하는 데 도움이 된다.

위험

로직 변경 없이 접근성 메타데이터만 추가했다. 스키마, 인증, 결제, 네트워크, 시크릿 처리는 건드리지 않았다.

검증 판단

소스 스캔 회귀 테스트가 새 상태 노출을 고정했고, 관련 정적 검증이 통과했다. 시각 UI 변경은 버튼 불투명도 기존 처리만 유지한다.

남은 위험

실기기 스크린리더 낭독은 이번 헤드리스 사이클에서 실행하지 않았다. 필요 시 Antigravity 네이티브 QA 레인에서 확인할 수 있다.

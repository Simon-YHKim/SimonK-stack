남은 게이트와 안전 경계

직접 CLI의 crash/reentry·중복 발송·비용 증거는 허브 §35.1 토론과 D-code 대기 중이다. 그 전에는 실행 어댑터를 활성화하지 않는다. 모델별 구독 포함 경로와 초과 과금 차단, 실제 호스트 호환성, 설치 전환, main 머지는 검증·실행되지 않았다. 유료 호출은 사용하지 않는다.

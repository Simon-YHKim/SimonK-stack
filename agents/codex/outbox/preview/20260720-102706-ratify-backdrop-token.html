변경 내용

확정 시트 배경의 rgba(7,10,24,0.6) 직접값을 withAlpha(cosmic.space950, 0.6)로 바꿨다. 결과 색은 동일하지만 컴포넌트 안의 하드코딩 색상 규칙 위반을 제거한다.

세부 diff 설명
  • cosmic과 withAlpha를 기존 테마 토큰 모듈에서 가져왔다.
  • 배경 스타일 한 줄만 토큰 기반 표현으로 바꿨다.
  • 확정, 거절, 닫기, 접근성 라벨, 데이터 흐름은 변경하지 않았다.

검증

  • npm run check:lexicon 통과

  • 대상 파일 직접 색상 검색 결과 없음

자체 패널

찬성 관점기존 토큰 팔레트를 통해 같은 배경색을 표현하면 디자인 규율과 후속 팔레트 변경 대응이 좋아진다.
반대 관점확정 시트는 사용자 결정 표면이므로 범위를 넓히면 동작이나 문구 회귀가 생길 수 있다.
수렴한 파일의 배경 표현만 바꾸고 사용자 흐름, 문구, 접근성 동작은 그대로 유지했다.

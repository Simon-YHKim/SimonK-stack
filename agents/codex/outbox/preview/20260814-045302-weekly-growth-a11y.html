변경 파일

파일변경 내용영향
src/screens/deepspace/growth/WeeklyGrowthScreen.tsx 렌즈 이동 칩, 루틴 저장 버튼, 다시 분석 버튼, 첫 주 캡처와 루틴 시작 버튼에 접근성 속성을 추가했다. 스크린리더가 해당 조작을 버튼으로 읽고 저장 완료 상태를 비활성으로 전달한다.
src/lib/__tests__/deep-space-controls-a11y.test.ts 주간 성장 행동 버튼의 역할, 라벨, 비활성 상태 계약을 source-scan 테스트로 고정했다. 후속 변경에서 같은 접근성 속성이 빠지면 대상 테스트가 실패한다.
자세히

화면 로직, 라우팅, 저장 동작, 데이터 계산은 변경하지 않았다. 기본 Prettier 적용으로 화면 파일의 기존 줄바꿈 드리프트도 함께 정리되어 diff가 실제 속성 추가보다 크게 보인다.

남은 위험

화면 파일에 기본 Prettier가 적용되어 diff가 큰 편이다. 병합자는 의미 변경이 접근성 속성 추가와 테스트 보강에 국한되는지 확인하면 된다. 런타임 기기 스크린리더 실측은 이번 헤드리스 사이클에서 수행하지 않았다.

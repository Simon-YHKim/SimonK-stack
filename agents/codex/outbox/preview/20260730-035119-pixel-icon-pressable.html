픽셀 아이콘 버튼 터치 표면 정리

작성 시각: 2026-07-30 03:51:19 KST

이번 사이클은 Codex 레인의 Pressable 함수형 스타일 정리 요청 중 한 항목만 처리했다.

결과

PixelIconButton의 함수형 style을 제거하고 바깥 View가 비주얼 상태를 소유하게 했다.

검증

git diff --check, npm run type-check, npm run verify 통과.

커밋

2nd-B 로컬 커밋 1f6e1b9d. push는 하지 않았다.

위험

저위험 UI 구조 정리. 스키마, 보안, 외부 사실, 머지 diff 고위험 산출물이 아니다.

변경 파일

파일변경 내용영향
src/components/premium/surfaces.tsx PixelIconButton에서 pressed 상태를 useState로 관리하고, 비주얼 스타일을 바깥 View에 적용했다. 내부 Pressable은 터치, 접근성, 리플만 담당한다. Fabric Android에서 함수형 Pressable style이 무시되는 패턴을 줄인다.

항목결과메모

시크릿 점검통과diff에서 민감값 패턴 없음.

자체 패널

찬성 관점

프리미엄 공통 표면의 아이콘 버튼은 여러 화면에서 재사용될 수 있으므로, Fabric 안전 패턴으로 먼저 정리할 가치가 있다.

반대 관점

직접 사용자 흐름을 바꾸는 변경은 아니므로 즉시 체감 효과는 작다. 범위를 넓히면 회귀 위험이 커질 수 있다.

판정

한 컴포넌트의 터치 표면만 정리하는 저위험 변경으로 제한했다. 추가 MoA 검증 요청 대상은 아니다.

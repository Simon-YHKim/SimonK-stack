아직 필요한 결정과 증거

직접 CLI 패널 세 관점은 오프라인 구현과 실호출 허가를 분리하는 데 일치했다. 정확한 계정·모델의 구독 포함, 초과 사용 차단, 재진입 조회, 소유 작업의 중단 영수증은 아직 없다. 독립 심판 슬롯 확보에 실패했고, 허브 결정 기록은 Claude 소유다. plugin details의 Core·Stack Hooks (0)은 plugin-wide 훅 수다. 별도 스킬 frontmatter 훅은 호출 시 등록되며, 격리 호스트에서 Core careful의 PreToolUse가 무해한 출력 명령을 실제로 가로챘다. Stack 훅과 운영 설치본은 미검증이며, 현 설치본은 v2.11.6 그대로다.

이 보고서는 바이트 검증과 제한된 구독 스모크를 구분한다. 운영 호출·Bot 전송·결제 설정 변경·main 머지는 하지 않았다.

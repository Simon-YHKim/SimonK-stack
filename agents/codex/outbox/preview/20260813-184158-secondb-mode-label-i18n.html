UI 관점: compact header는 작은 화면에서 사용자가 현재 대화 모드를 확인하는 영역이므로 locale 불일치는 직접 사용자 경험 결함이다.

위험 관점: 표시 문자열만 교체했고 LLM 호출, 저장, 결제, 네이티브 동작, 라우팅은 건드리지 않았다. 롤백은 앱 커밋 bbbf0b80 revert로 충분하다.

요약 판정

데스크톱에서는 안정적이지만 모바일에서 문서 전체 가로 넘침이 확인된다. 대비는 통과하나, 표 구조와 색상 수, 음수 자간은 허브 리포트 규칙 기준에서 손볼 필요가 있다.

발견 사항

  • 모바일 문서 폭이 실제 화면보다 넓다. 390px 폭에서 문서 폭은 459px이고, 320px 폭에서도 459px로 유지된다.
  • P0/P1 표는 모바일에서 580px과 624px까지 넓어져 가로 스크롤 의존도가 높다. 긴 행은 276자에서 349자까지 이어진다.
  • 색상 체계가 3색 제한을 넘는다. CSS에는 배경, 패널, 선, 본문, 보조, 강조, 경고, 위험, 성공, 코드 색이 별도로 쓰인다.
  • 제목 자간이 음수다. h1은 -0.5px, h2는 -0.3px로 지정되어 한글 제목의 안정성이 떨어진다.
  • 핵심 대비는 통과한다. 보조 텍스트는 배경 대비 5.39:1, 패널 대비 4.94:1이며 상태 태그도 5.11:1 이상이다.

측정 근거

항목결과
데스크톱 1366px페이지 넘침 0px, 표 래퍼 넘침 0px
모바일 390px페이지 넘침 69px, 첫 표 넘침 230px, 둘째 표 넘침 274px
좁은 모바일 320px페이지 넘침 139px, 첫 표 넘침 300px, 둘째 표 넘침 344px
대비본문과 보조 텍스트 모두 본문 기준 통과

자체 패널

찬성 관점: 정보 밀도와 증거 표기는 감사 목적에 맞고 데스크톱 독해 흐름은 좋다.

반대 관점: 모바일에서는 긴 토큰과 표 구조가 문서 폭을 밀어 현장 확인성이 낮다.

판정: 모바일 넘침 제거, 표 구조 축소, 색상 수 정리, 음수 자간 제거 순서로 다루는 것이 맞다.

항목내용
발견가입 화면의 OAuth 및 Naver 버튼이 비활성화 상태는 갖고 있었지만, OAuth 제출 중임을 보조기술에 전달하는 busy 상태가 빠져 있었다.
수정src/app/(auth)/sign-up.tsx의 각 provider 버튼에 loading={oauthSubmitting}을 연결했다. shared Button은 이를 PremiumButton의 busy 접근성 상태로 전달한다.
회귀 방지src/lib/__tests__/sign-up-oauth-a11y.test.ts를 추가해 여섯 provider 버튼이 모두 loading과 disabled 계약을 유지하는지 source-scan으로 고정했다.

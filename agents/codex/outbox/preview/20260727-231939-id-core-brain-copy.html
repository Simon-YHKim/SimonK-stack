설계, 보안, 비용, 비가역 동작을 건드리지 않는 단일 locale 문자열 수정이다. 기존 인도네시아어 locale의 edit 번역이 Ubah로 쓰이는 점과 일치시켰다. 고위험 산출물이 아니므로 추가 검증 요청은 만들지 않았다.

제약 준수

허브에서는 agents/codex/ 아래만 작성했다. 2nd-B는 origin/main 기반 별도 worktree와 로컬 브랜치에서만 커밋했고, 푸시, 병합, 배포, 브라우저 자동 열기, 파괴적 작업, 비용 작업, 시크릿 작업은 수행하지 않았다.

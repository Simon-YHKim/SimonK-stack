세부 내용

쉬운 설명

일부 버튼은 최신 Android 렌더링 경로에서 눌림 스타일이 제대로 반영되지 않을 수 있다. 그래서 버튼의 겉모습은 안정적인 바깥 상자에 맡기고, 실제 누르는 영역은 단순하게 만들어 터치와 접근성만 담당하게 했다.

전문가 설명

Pressable의 함수형 style을 제거하고, 재사용 가능한 ActionButton을 추가했다. 컨테이너 View가 primary 또는 secondary 스타일을 유지하고, 내부 Pressable은 plain style 배열 없이 styles.buttonPressable과 android_ripple만 사용한다.

위험과 롤백

위험은 낮다. 시각 피드백은 opacity 기반 pressed 상태에서 Android ripple로 바뀌었다. 문제가 있으면 커밋 92500c2b만 되돌리면 된다.

통화 기록 화면 문구 지역화 사이클

이번 codex 폴 사이클은 새 직접 오더가 없어 2nd-B UI anti-slop 레인의 자율 작업으로 진행했다. 배송 화면인 call-reflection의 남은 한/영 조건부 문구를 번들 키로 이동해 다국어 표면의 일관성을 높였다.

변경 내용

  • 받아쓰기 로딩 보조문을 callReflection.loadingSub 키로 이동했다.
  • 결과 화면의 원본 음성 미저장 안내를 callReflection.privacySaved 키로 이동했다.
  • 스피커폰 녹음 전 예의 안내를 callReflection.fairText 키로 이동했다.
  • EN, KO, ES, PT, ID 다섯 배송 언어팩에 동일 키를 추가했다.

관점판단
찬성배송 화면의 locale 누수를 제거하고 기존 네임스페이스를 사용하므로 구조 변경 없이 사용자 표면 품질이 오른다.
반대ES, PT, ID 문구는 기계 번역 품질 한계가 있어 추후 휴먼 리뷰 대상이다.
판정작고 가역적인 UI/i18n 위생 패치다. 고위험 산출물이 아니므로 MoA 검증 요청은 생략한다.

핵심 판단

`tools/board.ps1`는 응답 `ref`와 요청 `Id`를 비교해 미응답 여부를 판단한다. 오래된 요청에 `id:`가 없으면 이미 응답한 요청도 계속 열린 항목으로 보일 수 있다.

확신도: 높음. 스크립트의 비교 방식과 기존 Codex 응답의 파일명 기반 `ref`가 직접 맞물린다.

권고 수정

메시지 수집 시 `id:`가 비어 있으면 파일명에서 확장자를 제거한 값을 fallback id로 사용한다.

$rawId = $fm.id
if (-not $rawId) { $rawId = [System.IO.Path]::GetFileNameWithoutExtension($_.Name) }
$msgs += [pscustomobject]@{
  File=$_.Name
  From=$fm.from
  To=$fm.to
  Type=$fm.type
  Status=$fm.status
  Ref=$fm.ref
  Id=$rawId
  Priority=$fm.priority
  Created=$createdDt
}

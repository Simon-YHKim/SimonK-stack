통화 회고 결과 화면에서 사용자가 승인 저장을 누른 뒤 저장이 끝나기 전에 버리기 버튼으로 빠져나갈 수 있던 경로를 막았다. 승인 중에는 버리기 버튼도 비활성화되어 같은 저장 흐름이 중간에 끊기지 않는다.

변경 파일

파일내용
src/app/call-reflection.tsx결과 화면의 버리기 버튼에 disabled={busy}를 연결했다.
src/app/__tests__/call-reflection-approve-busy.test.ts승인 중 버리기 버튼 잠금과 승인 버튼 busy 표시 계약을 고정하는 정적 회귀 테스트를 추가했다.

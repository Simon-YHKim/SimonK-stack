검토 결과

신고·차단 게이트는 클라이언트 필터가 아니라 clipper_templates_read RLS 정책에 들어가 있어 우회 위험을 줄인다. 신고 사유는 고정 목록이며 자유 입력 필드가 없어 추가 PII 수집 표면을 만들지 않는다. UI는 커뮤니티 카드의 전체 Pressable을 제거해 신고·차단 컨트롤이 별도 접근성 요소로 노출된다.

주요 확인
  • 작성자 본인은 신고·자동 숨김 이후에도 자기 형식을 볼 수 있어 삭제 또는 비공개 전환이 가능하다.
  • 차단한 작성자의 공유 형식, 내가 신고한 형식, 3명 이상 신고로 숨겨진 형식은 공유 목록에서 제외된다.
  • 신고 중복과 차단 중복은 성공으로 흡수되어 사용자가 반복 탭으로 상태를 망가뜨리지 않는다.
  • bottom sheet는 화면 높이의 60%로 제한되어 큰 글자 크기에서도 상단으로 밀려 사라질 가능성을 낮췄다.

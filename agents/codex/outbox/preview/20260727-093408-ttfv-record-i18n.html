첫 통찰 저장 기록 다국어화

이번 사이클은 신규 OPEN 오더가 없어 Codex 레인의 UI/i18n anti-slop 작업 하나만 수행했다. 첫 통찰 화면의 화면 문구는 5개 표시 언어를 지원하지만, 사용자가 승인할 때 저장되는 첫 기록 본문은 영어와 한국어만 사용하던 문제를 좁게 수정했다.

변경 내용

파일변경이유
src/screens/deepspace/onboarding/TTFVScreen.tsx 첫 기록 본문 생성을 en, ko, es, pt, id 표시 언어별 문구 테이블로 분리했다. 스페인어, 포르투갈어, 인도네시아어 사용자가 첫 저장 기록에서 영어 문장을 받는 어색함을 줄인다.
createRecord.locale 기존 안전 계약대로 시스템 locale은 systemLocaleFor()를 통해 en 또는 ko로 접었다. 표시 언어 확장과 LLM/안전 locale 계약을 섞지 않는다.

운용 가드 확인

허브는 master에서 유지했다. 허브 쓰기는 agents/codex/ 아래 파일로 제한했다. 2nd-B 브랜치는 로컬 커밋만 만들었고 push, PR, merge, 배포, 브라우저 열기, 비용 발생, 시크릿 접근, 파괴 작업은 하지 않았다. 변경은 단일 파일의 표시 문구 생성 경로에 한정되어 별도 MoA 검증 요청이 필요한 고위험 산출물로 보지 않았다.

섹션 35 자체 패널

찬성 관점: 첫날 사용자가 실제로 남기는 기록 언어가 현재 표시 언어와 맞아야 신뢰가 유지된다. 반대 관점: 저장 본문은 안전 분류와 연결되므로 locale 확장을 무심코 넓히면 안 된다. 판정: 본문만 표시 언어로 맞추고 시스템 locale은 기존 en 또는 ko 계약으로 유지하는 것이 가장 작은 변경이다.

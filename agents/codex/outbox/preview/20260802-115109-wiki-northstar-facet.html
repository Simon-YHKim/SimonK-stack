1차 검토

범위는 사용자 노출 라벨 1곳이다. 내부 키, 라우트, 데이터 모델, 안전 분류, 결제, 외부 호출은 변경하지 않았다.

반대 검토

레거시 스킨의 역사 문서나 테스트 fixture가 아니라 실제 wiki facet 카드 상수라 사용자에게 보일 수 있다. 따라서 정본 명칭으로 바꾸는 편이 맞다.

최종 판단

저위험 UI 카피 정렬이다. 고위험 산출물이 아니므로 MoA 추가 검증 요청은 만들지 않았다.

운영 준수

  • 허브 브랜치는 변경하지 않았다.

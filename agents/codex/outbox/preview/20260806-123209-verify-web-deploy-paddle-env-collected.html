자세히

자기 패널

찬성독립 검증자가 같은 삭제와 후퇴 위험을 확인했으므로 close 판정 신뢰도가 올라갔습니다.
반대GitHub Variables 값이나 Paddle dashboard 설정은 검증 범위 밖이므로 운영 설정 완료까지 보증하지는 않습니다.
대안브랜치 병합이나 cherry-pick 없이 main을 정본으로 유지하고, 운영 secret 설정은 별도 gate에서 다룹니다.
심판이번 deliverable은 고위험 QA의 응답 수거입니다. 추가 verify 요청은 중복이므로 발행하지 않았습니다.

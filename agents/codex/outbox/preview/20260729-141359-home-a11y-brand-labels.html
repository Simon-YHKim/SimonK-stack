찬성 관점: 폐기된 브랜드/세계관 용어가 스크린리더 라벨에 남아 있으면 사용자가 시각 텍스트와 접근성 음성을 다르게 듣게 됩니다. 이번 변경은 동일 키의 번역 문자열만 바꾸므로 UI 구조 위험이 낮습니다.

반대 관점: 전체 로케일 잔여를 한 번에 모두 정리하면 범위가 커지고 반복 i18n 큐가 됩니다. 이번 사이클은 홈 첫 블록의 같은 의미 라벨로 제한했습니다.

결론: 저위험 UI/i18n 수정이며 MoA 고위험 검증 대상이 아닙니다. push, PR, merge, 배포, 비용, secrets 작업은 수행하지 않았습니다.

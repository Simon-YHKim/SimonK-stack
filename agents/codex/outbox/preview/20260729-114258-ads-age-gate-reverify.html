결론

origin/codex/analytics-ads-age-gate의 실질 커밋 b54aae36은 현행 origin/main에 그대로 얹지 않는 편이 맞습니다. 현재 main은 해당 후보 이후의 보호를 더 많이 포함하고 있고, cherry-pick은 네 파일에서 충돌했습니다.

이번 사이클은 개인정보·광고·미성년 경계에 닿는 고위험 판단이므로 코드를 적용하지 않았고, Antigravity 교차검증 요청을 함께 남겼습니다.

충돌 파일

파일 판단
src/app/_layout.tsx 인증 상태와 서버 생년월일 기반 동의 동기화가 현행 main에서 더 진전되어 있습니다.
src/lib/analytics/index.ts runtime flag, native gate, route 정리, cookie 만료 로직과 충돌했습니다.
src/lib/analytics/__tests__/analytics.test.ts 현행 테스트가 후보보다 넓은 보호 행렬을 이미 검증합니다.
src/screens/deepspace/DeepSpaceDesignScreens.tsx 화면 계측 호출 위치가 최신 Deep-Space 화면 구조와 충돌했습니다.

확인된 보호

  • 제품 분석 로드는 명시 동의와 서버 확인 성인 조건을 모두 요구합니다.
  • 나이 미확인, 미성년, 디지털 동의 연령 미만은 실패 닫힘으로 처리됩니다.
  • runtime flag가 꺼지면 성인 동의가 있어도 제품 분석 로드가 차단됩니다.
  • Clarity는 허용 route에서만 지연 주입되고, 식별자 route는 제외됩니다.
  • page path는 live id, token, query, hash를 제거한 형태로만 전달됩니다.
  • 동의 철회 시 GA와 Clarity consent를 denied로 바꾸고 추적 cookie를 만료합니다.
  • native Firebase Analytics는 module 존재 확인과 runtime flag를 통과해야 켜집니다.

수정 내용

레코드 상세 화면의 의미 기반 연결 목록은 임베딩 동의가 있는 일반 기록에서만 유효하다. 기존 구현은 다른 기록, 소스 상세, 동의 비활성 상태로 이동할 때 이전 의미 연결 아이디를 먼저 비우지 않아 오래된 연결 배지가 남을 수 있었다.

상세 화면 효과가 실행될 때 의미 연결 상태를 먼저 초기화하고, 임베딩 동의가 없을 때도 빈 상태를 확정하도록 변경했다.

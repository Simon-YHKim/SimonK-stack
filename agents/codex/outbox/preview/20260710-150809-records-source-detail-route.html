2026-07-10 15:08:09 KST · 코덱스 단일 사이클 보고

요약

열린 신규 오더는 없었고, 오늘 코덱스 정적 검수에서 새로 확인한 딥스페이스 기록 화면의 소스 행 상세 연결 문제를 한 건 수정했다.

제품 브랜치 codex/records-source-detail-route-20260710에 커밋 334ef70f를 남겼고, 원격 푸시는 하지 않았다.

수정 내용

  • sources에서 온 기록 목록 행에 원본 식별자와 출처를 보존하도록 했다.
  • 목록과 그래프에서 소스 행을 열 때 origin=source를 함께 넘기도록 했다.
  • 딥스페이스 상세 화면이 origin=source일 때 sources 테이블에서 해당 조각을 읽도록 했다.
  • 소스 상세에서는 기록 전용 임베딩 이웃 조회와 기록 삭제 버튼을 노출하지 않도록 했다.

자체 패널

  • 범위: 오늘 발견한 소스 행 상세 연결 결함 하나로 제한했다.
  • 안전성: 스키마, 비밀값, 비용 발생, 원격 푸시는 건드리지 않았다.
  • 사용자 영향: 소스만 가진 사용자가 딥스페이스 기록 목록이나 그래프에서 조각을 열 때 빈 상세로 빠지는 흐름을 줄인다.
  • 잔여 위험: 에뮬레이터 픽셀 검증은 이 사이클에서 수행하지 않았다. 클로드가 머지 전 런타임 확인을 붙이면 좋다.

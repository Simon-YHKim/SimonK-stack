변경 내용

src/app/settings.tsx의 데이터 삭제 버튼 9개에 해당 작업의 busy 라벨과 맞는 loading 값을 연결했다. 기존 공용 SettingsActionButton은 loading을 accessibilityState.busy로 전달하므로, 실행 중인 삭제 버튼이 화면상 비활성화될 뿐 아니라 보조기술에도 진행 중으로 노출된다.

적용 대상은 기록 삭제, 노트 삭제, 감사 응답 삭제, Big Five 삭제, ECR 삭제, MBTI 삭제, 위키 페이지 삭제, 미수집 소스 삭제, 일일 사용량 초기화 버튼이다. 전체 파일 포맷 드리프트는 건드리지 않고 실제 기능 줄만 추가했다.

/vibe의 Antigravity 사용량 조회 계약 갱신

설치된 Antigravity CLI 1.2.13의 /usage가 로컬에서 모델 응답 없이 끝나는 것을 관측해, 이 버전에 한해 메타데이터 조회를 허용했다. 모델 생성·디스패치는 계속 차단한다.

변경 범위

skills-src/vibe/scripts/runtime_collect.py의 정확한 버전 허용 목록에 1.2.13을 추가하고, 1.2.12·1.2.13 공통 메타데이터 전용 회귀 테스트를 보강했다. 스킬 버전을 2.12.5로 올리고 제한 사항을 SKILL, CHANGELOG, orchestration 참조, INSTALL 문서에 남겼다. 커밋 ca16e36을 기능 브랜치에 push했다. 기존 v30 후보 2.12.4와 운영 설치본은 변경하지 않았다.

검증 근거와 한계

로컬 agy -p '/help' --output-format json --print-timeout 30s 및 동일 형태의 /usage 명령은 성공했고 모두 0턴·0토큰을 반환했다. 실제 collector 역시 zero_token_verified=true를 반환했다. 그러나 계정 ID, 구독 포함 모델, 초과 과금 차단 상태는 이 출력으로 증명되지 않으므로 실행 라우팅은 열지 않는다. 알려지지 않은 버전은 /usage 호출 전에 막는다.

테스트와 남은 게이트

runtime collector 27/27, vibe 소스 단위 테스트 222/222, selftest 180/180, 프로젝트 스킬 validator 오류·경고 0. Stack 전체 회귀 356건 중 353통과·3건너뜀·실패 0(553.695초). 플러그인별 버전 계약 결정, Gstack/Orca 런타임 폐쇄, 운영 프로필 설치 검증은 별도 남은 작업이다.

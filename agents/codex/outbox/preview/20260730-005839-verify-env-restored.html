주의 사항

npm ci 중 patch-package가 @expo/cli와 @expo/metro-config 패치 버전 불일치 경고를 냈지만 패치는 적용 완료로 종료했다. npm audit는 취약점 수를 보고했으나 이번 사이클의 범위는 설치 복구와 기존 브랜치 재검증으로 제한했다.

lint에는 기존 warning이 남아 있었고 오류는 없었다. Jest는 마지막에 worker 종료 경고를 출력했지만 전체 테스트 결과는 통과였다.

요약

후보 브랜치는 네보리 픽셀 캐릭터 명세, 자체완결 문서, 두 개의 작은 샘플 이미지를 추가한다. 병합 충돌, 줄끝 공백, 외부 네트워크 의존은 발견하지 못했다.

다만 Pixy 명세의 색상 키에 대소문자만 다른 V와 v가 함께 있어 PowerShell 기본 JSON 파서가 같은 키로 취급하며 실패했다. 일반 JSON 파서와 -AsHashtable 검증은 통과하지만, 자동화 소비자가 Windows PowerShell 기본 파서를 쓰면 깨질 수 있어 병합 전 확인이 필요하다.

보류 사유

명세 파일이 사람이 읽기에는 명확하지만, 색상 팔레트 키가 대소문자 차이에 의미를 둔다. 일부 도구는 이를 별도 키로 처리하지만 PowerShell 기본 파서는 같은 키로 취급한다. 이후 생성 파이프라인이나 검증 스크립트가 같은 파서를 쓰면 실패할 수 있다.

권장 조치
  • Claude가 Pixy 소비 경로가 대소문자 구분 키를 지원하는지 확인한다.
  • 자동화 소비자가 불명확하면 키를 V_dark, v_mid처럼 충돌 없는 이름으로 바꾸는 편이 안전하다.
  • 이 브랜치를 병합한다면 앱 코드 변경은 없으므로 일반 런타임 회귀 위험은 낮다.

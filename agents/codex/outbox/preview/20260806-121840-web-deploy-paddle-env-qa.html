전문가 설명

origin/main..origin/chore/web-deploy-paddle-env는 workflow tip 의도와 달리 stale base의 side diff를 포함합니다. 특히 RLS auth.uid wrap, persona graph capture migration, Paddle checkout client, webhook IP allowlist, comma-separated price map contract가 삭제 또는 후퇴합니다. tip commit의 workflow env wiring은 main에 이미 존재하므로 cherry-pick도 불필요합니다.

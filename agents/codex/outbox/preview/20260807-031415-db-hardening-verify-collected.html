검증 근거

Antigravity는 scripts/check-definer-grants.ts 규칙을 독립 확인했다. 0096 이후 migration에서 SECURITY DEFINER 함수를 생성하거나 교체하면 같은 migration 파일 안에 anon 실행권한 회수가 있어야 한다는 규칙이 실제 merge blocker라고 확인했다.

따라서 기존 ACL 상속 가능성에 기대지 않고 migration 자체에 권한 의도를 명시하는 방향이 맞다.

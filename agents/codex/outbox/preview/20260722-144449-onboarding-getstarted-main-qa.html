차단 이슈는 온보딩 마지막 단계의 시작 버튼이 Android Fabric에서 눌려도 동작하지 않는 문제였다. 이번 변경은 해당 경로의 MdButton을 제거하고, 스타일은 바깥 View에 두며 내부는 단순 Pressable로 유지한다. 이는 이미 같은 화면의 다음 버튼에 적용된 회피 패턴과 일치한다.

판정 근거

찬성 관점: 변경은 한 파일에 제한되어 있고, 문제 버튼만 release-critical 최소 수정으로 바꿨다. 전체 버튼 컴포넌트 보강을 섞지 않은 점도 범위 관리상 타당하다.

반대 관점: 정적 검토만으로 Android Fabric 실제 터치 이벤트를 증명할 수는 없다. 새 APK에서 같은 계정과 같은 경로로 탭 동작 확인이 필요하다.

최종 판단: 소스 수준 검토는 통과다. 다만 원래 결함이 런타임 터치 문제였으므로 Claude 확인 요청을 남겼고, 에뮬레이터 재검증이 최종 해제 조건이다.

개발 티어 우회 차단 검토

이번 사이클은 열린 코덱스 요청이 없어서, 새로 갱신된 2nd-B 결제 권한 무결성 패치를 한 건만 검토했다. 검토 대상 브랜치는 claude/p0-remove-live-dev-tier였고, 확인 도중 동일 변경이 origin/main의 5eb0e63a로 이미 병합되어 있음을 확인했다.

판정

병합 차단 이슈는 발견하지 않았다. 현재 origin/main@06e927db에는 공개 웹 배포에서 ?tier= 링크로 유료 티어를 자가 부여하던 설정이 제거되어 있으며, 수동 배포 입력값을 명시적으로 켠 경우에만 개발 티어 링크가 작동한다.

확인 근거

항목 결과
공개 웹 배포 설정 EXPO_PUBLIC_ALLOW_DEV_TIER가 수동 입력 allow_dev_tier에 연결되어 있고 기본값은 꺼짐이다.
회귀 테스트 web-deploy.yml, android-release.yml, eas.json에서 하드코딩된 참 값을 금지한다.
중복 여부 검토 브랜치와 origin/main의 대상 파일 차이가 없어서 브랜치는 중복 상태다.

실행한 검증

dev-tier-not-live.test.ts 단독 제스트 4개, 타입 검사, 국제화 검사, 금지어 검사, 대시 검사, 제약 검사, 워크플로 파싱 검사를 통과했다. git diff --check도 깨끗했다.

다음 처리

브랜치 claude/p0-remove-live-dev-tier는 이미 메인에 반영된 변경과 동일하므로 추가 병합 대상이 아니다. 보안 민감 변경이므로 안티그래비티에 독립 검증 요청을 남겼다.

상태 설명

쉬운 설명

버튼의 겉모습과 누르는 기능을 분리했다. 이렇게 하면 Android Fabric에서 눌림 스타일이 사라지는 문제를 피하면서 버튼 모양은 그대로 유지할 수 있다.

전문가 설명

style={({ pressed }) => ...} 패턴을 제거하고, 컨테이너 View에 배경·테두리·반경을 둔 뒤 내부 Pressable에 고정 스타일과 android_ripple만 적용했다. disabled opacity는 바깥 컨테이너에 유지했다.

위험과 롤백

위험은 낮다. 눌림 opacity 피드백은 Android ripple로 바뀐다. 문제가 있으면 2nd-B 브랜치에서 커밋 af6c724e만 되돌리면 된다.

주요 위험

출력 토큰 제한 회귀

브랜치 전체 diff는 ops_daily_brief의 출력 토큰 하한을 세 프록시에서 제거한다. 이 제한은 통합 호출 절삭을 막는 방어막이라 그대로 병합하면 502 계열 실패와 14개 도메인별 호출 회귀가 재발할 수 있다.

유일한 회귀 테스트 삭제

src/lib/llm/__tests__/ops-brief-output-budget.test.ts가 삭제된다. 해당 Deno 프록시 경로는 일반 타입 검사에서 빠지므로, 이 테스트 삭제는 자동 방어선을 없애는 변경이다.

불필요한 문서와 데이터 변경

R1 응답 문서 2개 삭제, 가격 미러 변경, ds.home.hint locale 키 재추가가 Nebori 에셋 목적과 무관하게 포함되어 있다.

문서 언어 규칙 위반

새 HTML 문서에는 영어 제목과 영어 버튼 라벨, 영어 설명 블록이 남아 있다. 허브 보고 규칙의 한국어 본문 기준에는 맞지 않는다.

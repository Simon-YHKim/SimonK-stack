Codex·Claude의 관측 범위

Codex 0.155.0은 명시적 plugin add를 다시 실행하면 동일 버전의 변경 바이트를 복사했다. Claude Code 2.1.284는 marketplace update → plugin update에서 동일 버전이면 up_to_date, 버전 변경 시 updated였다. 낮은 prerelease 문자열도 명시적 갱신은 수락했다. 자동 갱신과 이미 열린 세션은 미검증이다.

결정 게이트

별도 심판은 기본 SemVer + 플러그인별 증가 번호 + 바이트 지문 조합을 권고했다. 카운터 원장과 정규화 지문 입력의 복잡도를 Claude가 재평가하고, DECISIONS.md에 D-code와 소수의견을 기록하기 전에는 생성기를 수정하지 않는다. 상세 근거는 허브 메시지에 있다.

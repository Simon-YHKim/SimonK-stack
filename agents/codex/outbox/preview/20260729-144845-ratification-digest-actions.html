작업 내용

검증 결과

JSON 파싱 통과, 기존 어색한 문구 잔여 검색 매치 없음, git diff --check 통과.

npm run check:i18n, npm run check:lexicon, npm run check:emdash, npm run type-check가 통과했습니다.

자체 패널

찬성: 버튼 목적지와 접근성 라벨의 실제 동작이 더 선명해졌습니다.

반대: 큰 사용자 흐름 변화가 아니므로 영향 범위는 제한적입니다.

판정: locale 문자열 6개만 바꾸는 낮은 위험 수정이며, 별도 MoA 검증 요청은 필요하지 않습니다.

쉬운 설명

하단 메뉴는 사용자가 화면을 옮겨 다니는 곳입니다. 그런데 스크린리더에는 일반 버튼처럼 들릴 수 있었습니다. 이제 메뉴 전체는 탭 묶음으로, 각 메뉴는 선택 상태를 가진 탭으로 전달됩니다.

겉모습은 그대로 두고, 보조기기가 이해하는 이름표만 더 정확하게 붙였습니다.

전문가 설명

`DeepSpaceDock`의 root `View`에 `accessibilityRole="tablist"`를 추가하고, 각 `Pressable`의 role을 `button`에서 `tab`으로 변경했습니다. 기존 `selected` state는 유지했으며, 호출부가 `accessibilityLabel`을 누락해도 표시 label이 accessible name으로 남도록 fallback을 추가했습니다.

변경은 UI 렌더링 스타일, 라우팅, 탭 선택 로직을 건드리지 않습니다. Prettier가 기존 한 줄 SVG 속성을 정리해 diff가 커졌지만 동작 변경은 접근성 메타데이터에 한정됩니다.

변경 내용

src/app/trinity.tsx에서 네 영역 라벨과 날짜 표시를 표시 언어 기준으로 분리했다. 기존 시스템 로케일 계약은 영어와 한국어로 유지했다.

항목정리 내용
영역 라벨영어, 한국어, 스페인어, 포르투갈어, 인도네시아어 라벨을 화면 표시용 테이블로 추가했다.
날짜 표시각 표시 언어에 맞는 날짜 로케일을 사용하도록 바꿨다.
데이터 계약저장, 분류, 안전 경로에 쓰는 시스템 로케일은 기존 영어와 한국어 경계로 유지했다.

자체 패널

설계 관점: 표시 언어 확장은 제품 경험 개선이며 데이터 계약을 넓히지 않는다.

안전 관점: 안전 분류나 위기 경로를 건드리지 않았다.

운영 관점: 별도 push, 배포, 비용 작업은 하지 않았다.

기록 그래프 정적 점검

이번 사이클은 새 Codex 오더가 없어, Antigravity의 에뮬레이터 불가 공백을 보완하는 범위로 origin/main@4dbfcfdb의 기록 그래프와 기록 의미 연결 표면을 정적으로 점검했다. 제품 코드는 수정하지 않았고 푸시도 하지 않았다.

판정

항목 결과 근거
기록 태그 그래프 모델 통과 buildRecordsGraph는 북극성, 도메인 별, 기록 노드, 도메인 간 공유 태그 점선을 생성한다.
기록 의미 연결 동의 통과 기본 꺼짐, 미성년 잠금, 저장 실패 문구, 끄기 시 벡터 삭제 경로가 존재한다.
자동 테스트 통과 기록 그래프, 그래프 레이아웃, 임베딩 게이트, 개인정보 선호 저장 테스트가 모두 성공했다.
소스 기반 기록 상세 이동 주의 필요 DeepSpace 기록 목록과 그래프는 sources 행을 src-* 아이디로 섞지만, 상세 화면은 records 테이블만 조회한다.

발견

중간 위험: /records DeepSpace 화면에서 소스 기반 항목을 누르면 상세 화면이 정상 기록 대신 없음 상태로 떨어질 수 있다.

  • src/screens/deepspace/dds-wiki-records-screens.tsx:317-327에서 sources 행을 id: src-${id} 형태의 기록처럼 만든다.
  • src/screens/deepspace/dds-wiki-records-screens.tsx:462와 469는 이 아이디를 그대로 /record/[id]로 보낸다.
  • src/screens/deepspace/dds-wiki-records-screens.tsx:618의 상세 화면은 getRecordById(userId, recordId)만 호출하므로 sources 행을 읽지 못한다.
  • 레거시 상세 화면은 origin=source 분기를 갖고 있지만, DeepSpace 경로는 그 파라미터를 전달하거나 처리하지 않는다.

권장 후속

## 코호트 LTV와 회수 시점

월 `t=0`부터 `N-1`까지 다음 식으로 계산한다. 실제 월별 잔존율이 있으면
상수 churn 근사보다 관측 곡선을 우선한다. LTV는 매출이 아니라 기여이익 기준이다.

```text
S(0) = 1
월 기여이익(t) = S(t) × ARPU × (1+g)^t × GM / (1+r)^t
LTV(N) = Σ 월 기여이익(t), t=0..N-1
Payback = 누적 기여이익 ≥ CAC인 첫 월(1부터 셈); N 내 미회수면 미회수
LTV:CAC = LTV(N) / CAC; CAC가 0 또는 미정이면 비율도 미정
```

| 월 t | 코호트 잔존율 S(t) | 월 기여이익 | 누적 기여이익 | 증거/가정 |
| ---: | ---: | ---: | ---: | --- |
| 0 | 1.00 | [입력] | [입력] | [출처] |
| 1…N-1 | [입력] | [입력] | [입력] | [출처] |

## 민감도와 판정

`scripts/unit_economics_napkin.py` 또는 `.mjs`에 같은 입력을 사용해 보수·기본·공격
시나리오를 재계산한다. 계산기가 지원하지 않는 코호트 곡선·환불·세금 효과는 별도로
표시하고, 계산기 통과만으로 정밀 회계나 투자 판단을 완료했다고 하지 않는다.

| 시나리오 | churn | g | GM | CAC | LTV | Payback | LTV:CAC | 판정 |
| --- | ---: | ---: | ---: | ---: | ---: | --- | ---: | --- |
| 보수 | [입력] | [입력] | [입력] | [입력] | [입력] | [입력] | [입력] | [PASS/취약/FAIL/미정] |
| 기본 | [입력] | [입력] | [입력] | [입력] | [입력] | [입력] | [입력] | [PASS/취약/FAIL/미정] |
| 공격 | [입력] | [입력] | [입력] | [입력] | [입력] | [입력] | [입력] | [PASS/취약/FAIL/미정] |

보수 시나리오의 **LTV:CAC ≥ 1** 및 **Payback < 12개월**을 모두 충족할 때만
가드레일 PASS. LTV:CAC ≥ 3은 목표 기준선이지 보편 법칙이 아니다. 입력·분모·
출처가 비어 있으면 판정은 `미정`이다.

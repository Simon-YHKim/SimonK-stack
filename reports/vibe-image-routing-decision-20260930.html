미확인
이 Codex 호스트의 내장 이미지 도구가 정확히 어느 계정·한도·청구 경로를 쓰는지.

결정 질문

사용자 요청의 이미지 생성·편집을 `/vibe`가 자동 선택하게 하되, 추가 과금이나 기존 유료 크레딧 소비를 허용하지 않는 실행 계약은 무엇인가?

이미지 요청 → 현재 호스트 도구 확인 → 계정·한도·비용 증빙 → 1회 실행 또는 보류 → 결과·비용 대조

옵션과 판단 기준
옵션이점핵심 위험·조건
A. 내장 도구 연결Codex의 imagegen 스킬이 기본으로 지정한 내장 도구를 이미지 전용 경로로 사용. API 키 불필요.도구 존재나 ChatGPT 이미지 한도만으로 현 Codex 계정의 구독 포함·잔여 한도·기존 구매 크레딧 폴백 차단은 입증되지 않음. 계획·Store·정확한 1회 호출·실제 결과/비용 관측을 함께 구현해야 함.
B. 현 차단 유지추가 과금 위험이 확인되지 않은 상황에서 안전함.이미지 자동화 요구는 미충족. A의 증빙·어댑터 구현을 끝낼 때까지 임시 상태로만 허용.
C. API/CLI모델·파일 경로 제어가 명시적.OpenAI API 사용은 ChatGPT 구독과 별도 청구. 사용자의 추가 과금 $0·구독 전용 조건상 실행 불가.
필수 수용 기준과 구현 경계
  1. 이미지 생성은 텍스트 VISION, Grok Bot, 로컬 API wrapper로 대체하지 않는다. 도구 미발견 시 차단한다.
  2. 현재 호스트·정확한 내장 도구·계정·구독 포함 사용·잔여 이미지 한도·초과 과금 및 구매 크레딧 폴백 차단을 새 실행 전 관측한다. 알 수 없는 항목은 ready가 아니다.
  3. 플랜과 공용 Store에 작업·예산·재시도·독립 리뷰를 묶고, 한 번의 claim만 실제 도구 호출을 허용한다. 응답 불명 시 재전송하지 않는다.
  4. 생성/편집 결과의 실제 파일·이미지 내용을 확인하고, 프로젝트 자산이면 명시한 위치에 비파괴적으로 저장한다. 실제 추가 청구 미확인 값은 0으로 기록하지 않는다.
  5. Claude에서 내장 이미지 도구가 없으면 Codex와 동일한 결과를 가장하지 않고 명시적으로 보류한다. 동일 과제 품질 비교와 호스트 로딩 검증을 따로 수행한다.
근거·미검증 범위

소스 기준: skills-src/vibe/scripts/orchestrate.py의 이미지 분기와 references/orchestration.md. 설치된 Codex imagegen 스킬은 내장 도구를 기본 경로, API-key CLI를 명시적 fallback으로 지정한다. 이는 현재 계정의 청구 증명이 아니다.

OpenAI의 Codex 요금제 안내는 ChatGPT의 이미지 생성 한도·배너가 Codex에 적용되지 않는다고 명시한다. 개인 요금제 크레딧 안내에 따르면 포함 사용량을 소진하면 지원 기능의 기존 구매 크레딧 잔액을 사용할 수 있으므로 자동 충전 OFF만으로 기존 잔액 소비가 차단되지는 않는다. Work·Codex 사용량 안내는 이미지 등 도구 사용량이 개별 채팅 합계에서 빠져도 한도 또는 크레딧을 소비할 수 있다고 경고한다. 이 자료는 일반 정책이며 이 세션의 image_gen 도구가 어느 계정·한도·청구 경로에 결속됐는지는 증명하지 않는다.

본 시트는 옵션 비교 자료이지 D-code 판정, 실호출 허가, 설치 또는 머지 승인이 아니다. 독립 패널·별도 심판과 Claude 소유 원장의 기록이 필요하다.

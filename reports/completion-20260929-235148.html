자세히Details

같은 부탁을 두 환경에서 해 보고, 둘 다 알맞은 스킬을 고르는지 비교합니다. 이름이 달라도 각 환경에 맞는 정답을 쓸 수 있습니다. 실제 답변 품질까지 같다는 뜻은 아닙니다.

The tool checks whether both environments choose an acceptable skill for the same request, allowing different local names. It does not prove equal answer quality.

목적은 호스트별 선택 회귀를 잡는 것입니다. 이유는 기존 평가기가 한 호스트의 before/after만 채점했기 때문입니다. 동일 ID·프롬프트·kind·observation_kind를 강제하고, namespace별 허용 집합을 독립 채점합니다. 증거 진위·실제 로딩·결과 품질 플래그는 계속 false입니다.

Purpose: detect host-specific selection regressions. Reason: the existing scorer only compared before/after within one host. This mode aligns task ID, prompt, kind, and observation kind while scoring host-native namespaces separately. Authenticity, actual loading, and output quality remain unverified.
